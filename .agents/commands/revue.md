---
description: Review Little Things changes before submission
---

## Goal
Review the current changes without modifying the code.

## Rules
- Do not edit any files during the review.
- Report findings honestly.
- Do not claim that tests passed unless they were run.

## Procedure
1. Inspect the modified files.
2. Check for potential regressions.
3. Check relevant error-handling paths.
4. Run available tests and checks.
5. Report findings by severity.

## Expected output
- Blocking issues
- Potential improvements
- Checks performed
- Remaining uncertainties
